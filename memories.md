# Metaforge — memories.md

## People
- Alex — wants a morning brief. Prefers it short, ready before 7am.
- Jordan — wants reminders. Forgets to call family; a nudge the evening
  before works better than one the same morning.

## What has been built
- A morning brief — renders each morning with the day's focus for each
  person. Built from the first conversation.
- Reminders — set from a plain sentence ("remind me to call mom") and
  kept on the roadmap as a phase.

## Decisions
- The file is the product. Everything else — the model, the server, the
  schedule — grows out of it; nothing replaces it.
- Local first. Nothing leaves the machine unless the user points at a
  server of their own.

## Preferences
- Short answers first. Detail only when asked.
- The morning brief is the day's anchor; everything else hangs off it.
